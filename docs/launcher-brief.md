# 浮窗界面约定

更新：2026-10-29。模式：Operate；原生 macOS / AppKit。实现授权与历史审核状态见 [prototype.md](prototype.md)。

## 方向

一个可移动、可缩放的深色工具浮窗，分类、列表和详情逐层切换。外壳的颜色、透明质感、边界和阴影以用户提供的 ChatGPT Companion 对照截图为依据；内部使用紧凑的系统字体和 SF Symbols。保持文字清楚、操作安静，不在界面堆放产品宣传或实现说明。

## 布局

- 初始 620 × 520 pt，最小 360 × 300 pt。缩小时重排和滚动，保持字号。
- 固定顶部 54 pt 区域与底部操作，中间滚动。页头可拖动，边缘可缩放。
- 主要内容左边缘为 24 pt：列表标题、详情标题、详情容器和底部分隔线对齐。分类图标位于同一外层起点，名称为图标留位；容器内四段统一再缩进 16 pt。
- 分类行含图标与名称，高 44 pt；条目行保留标题和简述，高 64 pt。右箭头距行右缘 20 pt。
- 顶部保留返回、当前位置、关闭；不在右上重复显示应用名。
- 详情只用一个轻边框容器，依次为原始经验、来源、解释、Prompt，段间细线。正文支持原生选择；仅围栏代码使用等宽字体。
- 复制、插入为右下图标按钮，分别提供「复制完整 Prompt」和目标/快捷键提示。错误反馈出现时增加底部高度，操作仍可到达。

## 行为

`↑↓` 选择；Return 只在前两层打开，详情页不操作。Shift + Return 只在第二、三层返回，在分类页不操作。Escape 保持返回兼容行为，在分类页隐藏；`⌘Return` 只在详情页插入。文本选择和输入法组合由原生文本控件处理。

全局默认 `⇧⌥Space`：隐藏时显示，可见时隐藏，即使焦点已离开。菜单可选 `⌃⇧Space`；注册新键失败保留旧键。切换不重建页面，保留选择和滚动；重新显示时重新捕获插入目标。

显示为 0.18 秒轻微舒展与淡入，收起为 0.12 秒回收与淡出；快速切换可反向中断，不更改窗口尺寸和位置。减少动态效果或交接插入焦点时立即切换。

页面前进为从右侧 16 pt 内移入并淡入（0.18 秒），返回从左侧移入（0.16 秒）；旧内容向反方向轻移 10 pt 并淡出。外壳、导航、操作栏不移动。快照只包含本应用的内容视图，不捕获桌面背景；切换结束、缩放和隐藏会清理快照。

详情复制原始完整 Prompt；插入只填写捕获的输入框，不发送。权限、目标、内容/选区变化或回读失败给出具体反馈，保留当前条目与复制。

## 材质与验收

使用系统 HUD 背景材质、中性偏暖的炭灰遮罩、连续圆角、细边界与系统阴影；键盘焦点描边使用中性白。降低透明度时改用不透明底色，提高对比度时增强外边线；减少动态效果时不播放内容淡入。

最新颜色对照来自 `Screenshot 2026-10-29 at 07.50.56.png`。当前匹配深色背景的主导中性色接近 Companion，取样与限制见 [prototype.md](prototype.md)；系统材质随背景变化，保持透色与文字清晰。

视觉 token 以 [DESIGN.md](../DESIGN.md) 为准。公开运行截图见 [界面基线](prototype.md)，每轮本地原始截图生成于 `artifacts/ui/`；构建、复制、键盘、尺寸与反馈各自依据实际结果记录。真实 Codex 核心插入、不发送已由用户实测确认，证据与范围见 [prototype.md](prototype.md)。当前七条项目示例不等于正式经验库，也没有后端或持久化编辑。
