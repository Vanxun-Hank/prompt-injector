# 浮窗视觉更新 · Figma 提案

模式：Operate。沿用用户已确认的内容管理视觉语言，Figma 草稿已完成；用户随后明确授权移植，当前已接入 AppKit 开发版。原生行为见 launcher-brief.md，审核与验收状态统一见 prototype.md。

## Direction contract

**THESIS**：浮窗仍是快速调用入口，分类、条目、详情逐层切换；将已确认的内容管理语言收敛到小窗口，不增加侧栏、统计或编辑功能。

**OWN-WORLD**：中性深黑外壳、炭灰内容面、深灰选中行；通用文字和图标为白色，辅助文字为灰色。沿用发光渐变 Logo；按用户最新反馈去掉全部分类色点，让五种分类名称及顶部当前分类文字直接带同色柔光。按钮使用复制按钮的透明底和细灰边框。Figma 中 SF Pro 虽可加载但实际导出缺字，英文与快捷键改用已验证的 Inter，中文使用 Noto Sans SC；此为预览字体，客户端继续使用系统字体。

**STORY**：选择分类，浏览标题与简述，检查完整 Prompt，再复制或插入已捕获的输入框。详情页以“Prompt / 经验与来源”分段查看，Prompt 默认在首屏；另一段将原始经验、来源、解释独立呈现。分段切换已接入原生控件。

**FIRST VIEWPORT**：默认 620 × 520，最小 360 × 300。固定顶部导航和底部操作，中部滚动；默认左右 24 留白，最小窗口 16。分类无逐行外框，选中项使用深灰底。复制和插入为同样式纯图标按钮，保留明确的操作名称和快捷键说明。仅详情页出现插入。

**FORM**：直接延伸已确认的管理界面，不再开启风格选择。制作三级默认与最小尺寸、详情经验分段、目标失效状态；全部内容使用本项目七条种子记录。界面不显示目标应用标签，插入仍使用唤起时捕获的原输入框；设计工具不代表已捕获真实输入框。

**FINISH**：按实际尺寸检查文字、滚动边界与底部操作，完成原生截图对照、完整套件、独立 finish review 与 DESIGN.md 文档交接后再登记完成。静态提案不代表系统插入、窗口缩放或辅助功能已完成验收；本轮原生检查与独立修正项复核已通过；真实跨应用插入未重测。

## 行为边界

保留 ⇧⌥Space 显示／隐藏、↑↓ 选择、前两层 Return 打开、第二和第三层 ⇧Return 返回、Escape 返回／顶层隐藏，以及详情 ⌘Return 插入。插入只填写，不发送。目标失效时明确原因、禁用插入并保留复制；正文、来源和用户编辑不被覆盖。

## 试用后的文案精简

分类名称、数量、右箭头与返回页头按可见字形中线对齐。条目标题与简述作为整体居中；紧凑排版由窗口宽度判断，行间距不参与模式选择。

详情标题下不再重复显示来源行，原始来源仍在“经验与来源”分段中可读。正文、来源与解释字段不做删除；操作快捷键和具体错误继续显示。
