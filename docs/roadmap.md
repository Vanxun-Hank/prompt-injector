# 阶段与验收

当前状态（2026-10-30）：**Stage 1 在当前 macOS / Codex 普通主输入框范围验收完成**。已有 SQLite 分层存储、真实在线/断网插入不发送、未授权拒绝和复制降级、原输入框失效保护、性能基线与完整回归套件。证据与边界见 [stage1-acceptance.md](stage1-acceptance.md)；不自动开始 Stage 2。原型沿革和授权记录仍在 [prototype.md](prototype.md)。

## Stage 1 · v0.1 · 快捷调用

范围：全局快捷键唤起/隐藏，同一浮窗三级导航，点击与键盘操作，SQLite 示例内容，详情复制与插入，权限和目标失效反馈。首个真实目标为 Codex 普通主输入框，插入后不发送。question 自由回答框的兼容性不属于 Stage 1 阻塞项；已知空行回读差异留待后续。

已实现：可移动、缩放并记忆几何的原生浮窗；五个分类与七条示例；保留页面、滚动和选择的导航；窗口及页面切换动画；快捷键切换及注册失败保留原键；可选择正文、完整 Prompt 复制；辅助功能目标捕获、校验与 Codex 标准粘贴。真实 Codex 插入、不发送已由用户操作确认，并有完整回读验证。

已完成 SQLite 持久化及后台分类/摘要/正文按层查询，首次导入事务与回归套件见 [testing.md](testing.md)。

剩余非本阶段阻塞项：其他应用和最低系统兼容性、大规模库与长时间性能。上述核心系统场景及初步性能已完成，细节见验收报告。JSON 只用于首次建库导入，后续启动不读取种子正文。

验收：从 Codex 输入框唤起，选择并插入正确 Prompt，且不发送；断网也通过。未授权或目标失效时不错误写入，可复制。记录样本量及性能；截图和模拟目标不能替代真实系统验收。

不含：搜索、管理窗口、LLM、云端同步、其他应用兼容承诺。

## Stage 2 · v0.2.x · 内容维护（未实现）

详细拆分见 [stage2-plan.md](stage2-plan.md)：先完成 v0.2.0 新增闭环，再依次编辑、搜索、导出、导入和删除，每个版本独立验收和回滚。

范围：独立管理窗口，手动新增/编辑/删除，固定分类，标题和简述搜索，JSON 导入导出。字段包括标题、简述、原文、作者/来源、解释和 Prompt。

验收：新条目保存后浮窗及时显示；重启后保留；导出再导入保留 ID 与字段。保存失败不得表现为成功。

## Stage 3 · v0.3 · AI 整理（未实现）

范围：Go + chi 单一整理接口和一个模型服务。原文先存本地草稿；返回已有分类中的候选；用户编辑、确认后写入 SQLite 正式库。不需要 PostgreSQL。

验收：真实经验可整理、编辑、保存后调用。超时、失败、取消均保留草稿；重新生成保留手改结果，明确采用候选才替换。

## Stage 4 · v0.4 · 云端保存与同步（未实现）

范围：PostgreSQL 正式内容、稳定 ID 迁移、SQLite 缓存和草稿；启动/保存后/手动刷新；版本检查、删除传播、独立备份。私人接口使用访问凭证，无注册登录 UI。

在线修改正式条目并更新缓存；离线浏览、搜索、插入缓存并保存本地草稿。

验收：迁移不丢失、不重复；修改与删除可刷新；版本冲突不静默覆盖；断网可调用。刷新失败保留上次成功缓存并显示状态。

## 及时更新的含义

本地：保存事务成功后发送内容变更事件，刷新受影响数据并保持选择；下次唤起必须看到已保存版本。

云端：约定事件触发刷新，成功后一次性更新缓存。失败可重试；首版不要求 WebSocket 或持续轮询。
