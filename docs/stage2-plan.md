# Stage 2：把只读 Prompt 库变成可维护的个人库

状态：v0.2.0 手动新增已完成自动化与当前环境的最小闭环复核；用户确认重启后条目仍在，并在修复包的 Codex 普通主框成功插入新增 Prompt。本轮按授权交付源码，不含新标签或安装包发布。其余小版本仍为计划。Stage 1 的快捷键、三级浮窗、磨砂样式、插入校验及“不自动发送”行为保持不变。此阶段不接 LLM、账号、后端或同步。

## 第一个最小可用版本：v0.2.0

实现、验证与剩余人工步骤见 [stage2-acceptance.md](stage2-acceptance.md)。保存失败/关闭窗口保留的是当前进程内表单，退出应用前未保存内容不会跨进程恢复；持久化草稿仍属 Stage 3。

只打通 **新增一条 → 保存 → 浮窗找到 → 插入 → 重启仍在**。

菜单栏增加“管理内容”入口，打开独立原生管理窗口。先提供新增表单：固定分类、标题、短描述、原始经验、来源、解释、完整 Prompt。复用当前字段；作者信息暂写入来源，不提前设计作者实体或数据库新列。

标题和 Prompt 为必填；错误反馈贴近字段，保存失败保留表单，连续点击保存不产生重复。使用稳定 UUID、参数化 SQL 和事务；沿用 schema v1，排序值在同一事务中分配。提交成功后通知浮窗刷新受影响分类；保留仍有效的选择，按稳定 ID 跟踪当前条目，详情重新加载后才允许插入。

**验收场景**：手动录入含中文、emoji、多行代码的真实经验，保存后立即在浮窗找到；复制/插入的 Prompt 与所填内容完全一致，重启后 ID 与字段不变。失败保存和重试不会丢输入或产生重复。

**测试**：repository 插入/回读、约束失败回滚、重复提交防护、落盘后重开；管理窗口保存成功/失败状态；列表刷新与详情迟到结果丢弃；保留 Stage 1 全套回归，最后真实 Codex 主框验证不发送。

**回滚**：撤销新增入口与写入代码即可回到只读使用；已保存条目仍在 schema v1 中，旧版能读取。不要在代码回滚时删除新数据。

## 后续小版本

每行都是独立闭环、提交/标签及验收点，按依赖顺序实施。

| 版本 | 最小功能 | 可验证结果与新增测试 | 回滚边界 |
| --- | --- | --- | --- |
| v0.2.1 | 编辑已有条目 | 修改分类/正文后浮窗同步变化，稳定 ID 不变；测试保存失败、取消/关闭未保存编辑、刷新后旧 Prompt 不可插入 | 回滚编辑入口；已修改内容保留。恢复旧内容需备份，不靠 revert |
| v0.2.2 | 搜索标题与短描述 | 浮窗列表内本地文本搜索，空查询恢复，中文可查，空结果清楚；测试 `%`/`_` 字面量、参数绑定、快速输入迟到结果、返回选择 | 撤销查询/UI 变化，数据不变；不改为正文搜索或 AI 搜索 |
| v0.2.3 | JSON 导出备份 | 导出所有字段、稳定 ID、格式版本；测试 Unicode/换行保真、导出失败不显示成功、快照一致 | 撤销导出入口，已有备份文件仍可保留 |
| v0.2.4 | JSON 导入恢复 | 预览新增/冲突数，确认后事务导入；同 ID 同内容跳过，同 ID 不同内容明确冲突，首版不静默覆盖；测试坏 JSON、未知版本/分类、批次回滚、重复导入、导出导入往返 | 代码可 revert；已导入数据需导入前备份恢复，不能自动批量删“新增项” |
| v0.2.5 | 删除条目 | 显示准确条目标题并确认，删除后列表/详情失效、不能再插入旧缓存；测试取消/失败/重启、删除当前条目、从导出备份恢复 | 回滚删除入口不会恢复被删数据；使用已验证的导出/导入恢复 |

删除排在备份与恢复之后，避免只提供不可恢复的内容破坏操作。不要把“编辑、搜索、导入、删除”捆成一次大提交。

## 共用完成条件

1. 每个小版本保持一个可用闭环，写清数据和 UI 边界。
2. 保存事务失败时保留用户输入，不能以成功提示掩盖失败。
3. 写入仅经 repository；数据库工作继续在后台串行队列，查询保持按层加载。
4. 正文、来源、生成内容分离；日志只增加固定元数据，不记录私人正文。
5. 新案例加入 test suite，执行 `python3 scripts/test-suite.py`；真实系统交互仍按范围复核。
6. CHANGELOG、bug/test 记录、提交正文同步维护；标注可回滚范围及不可逆数据影响。
7. 验收通过后，按当次授权提交或打对应标签；未获发布授权时保留工作树供审查，不自动发布。

schema v1 的原始字段与普通文本查询足够覆盖这些小版本。若实际实现证明需要 schema v2，先暂停依赖该变化的写入工作，补迁移/兼容/备份测试与回滚方案，再单独提交，不顺带改表。
