2026-11-04。用户在上一轮 V7 十项修复后明确授权完整 UI 移植；原型与实现状态以 [prototype.md](prototype.md) 为准。Figma 使用已修复的 [V7 画布](https://www.figma.com/design/2HmvWbRy3wnjiMOwrbh6A6?node-id=386-1661)，没有改用旧稿或增加聊天。

## 已实现

- 全部内容默认紧凑卡片网格，默认三列、最小窗口两列；卡片只加载摘要和来源，点选后才读取完整正文。保留精确 categoryID＋搜索 AND 和查询代次保护。
- 阅读与已有条目原位编辑共享列表／详情容器；保存或返回保留有效筛选、稳定 ID 与网格滚动。标题、简述、分类、Prompt、作者原文和整理说明沿用已有字段；复制／编辑／更多删除的操作区域不变。
- 原文或链接、手动填写在录入页切换，保留已贴 Prompt。普通必填错误在字段旁显示并聚焦，不弹 Modal。
- 单条和多条共用工作台：左侧当前条目与批量复选框独立，右侧编辑当前候选；作者原文可折叠查看，来源保持只读。生成、待确认、已确认分别由条目状态驱动，修改取消确认，正式保存仅接受已确认集合。
- 生成不跳独立审核页；部分保存继续显示剩余项及准确分母，保存全部后显示完成状态。重开恢复未保存草稿。手贴可跳过模型请求，重新生成仍先比较、明确采用。
- 沿用已有 AppKit 控件、十五色循环、来源标记与 Figma 资源。没有数据库 schema 迁移、服务依赖、配置开关或插入路径变更。
