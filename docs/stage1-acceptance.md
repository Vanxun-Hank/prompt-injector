# Stage 1 验收摘要

2026-10-30，v0.1 在 **当前 macOS 与 Codex 普通主输入框**范围内完成验收。此文是可公开的结果摘要；原始日志、会话标识、性能 profile 和逐轮测试产物留在本地 `artifacts/`，不随仓库发布。其他开发者可运行测试入口复验自己的环境。

实际环境：macOS 27.2、Apple Silicon、18 GiB 内存，debug 构建。工程最低部署目标为 macOS 14，但不据此声称该版本已验收。

## 使用流程与失败保护

| 案例 | 结果 |
| --- | --- |
| 普通主框插入 | 用户确认原文本保留、完整追加、未发送；程序全文回读 verified，并恢复原剪贴板 |
| 断网调用 | 用户断开联网通道后完成本地浏览、选择与插入，无报错或发送，随后恢复网络；程序全文回读一致 |
| 关闭辅助功能权限 | 实际进程 trusted=false，在写入前拒绝；原框不变，复制与手动粘贴可用；恢复权限后实际进程 trusted=true |
| 捕获后切换聊天 | 在激活目标前发现 targetLost，没有写入请求；用户确认没有误写或发送，错误反馈保留 |
| SQLite | 首次事务导入 5 类/7 条，保留稳定 ID 和字段；重启不重复，分类/摘要/正文按层查询；故障与并发回归通过 |
| UI 与键盘 | 三级导航、复制、几何记忆、三种尺寸、动画与中断、IME 防护、Return/Shift+Return/⌘Return 路由均纳入原生检查 |

物理断网与未发送由真实用户观察确认，不由程序日志单独证明。测试模式不捕获外部输入框，也不替代这些真实系统验收。

## 性能基线

4 次真实主输入框热唤起样本，跨本轮两个构建：显示调用完成 19–27 ms，动画完成 200–208 ms。从应用收到唤起请求起计时，包含捕获与显示，不包括硬件按键和系统派发。应用与 SQLite 已打开；不把这些结果称为冷启动或稳定 P95。

每轮空闲采样约 30.4 秒、31 个样本，使用累计进程 CPU 时间差；100% 表示一个核心。RSS 是驻留内存，不等于活动监视器 memory footprint。

| 状态 | CPU 平均 | RSS 中位 | RSS 范围 |
| --- | ---: | ---: | ---: |
| 浮窗显示，首轮 | 3.09% | 56.45 MiB | 50.97–56.66 MiB |
| 浮窗显示，复测 | 0.16% | 47.73 MiB | 47.72–53.39 MiB |
| 同进程浮窗隐藏 | 0.00%* | 56.73 MiB | 56.20–57.38 MiB |

*隐藏轮累计 CPU 增量为 0.00 秒，采样工具精度 0.01 秒，不等于绝对零开销。首轮波动保留；随后短时采样栈只见线程等待，未发现持续忙循环证据。这是初步比较基线，不是长期内存上限、无泄漏证明或预设 SLA。
